# IRIS
### Intelligence and Recognition Identification System

A computer vision pipeline for real-time face detection, recognition, and behavioral analysis. Built as a foundation for security and digital forensics tooling.

---

## Phases

| Phase | Feature | Status |
|-------|---------|--------|
| 1 | Face Detection — bounding boxes on images, video, and live webcam | 🔨 In Progress |
| 2 | Face Recognition — identity enrollment and real-time matching | 🔒 Upcoming |
| 3 | Face Analysis — age estimation, emotion, and liveness detection | 🔒 Upcoming |
| 4 | AI Face Detection — classifying real vs AI-generated faces | 🔒 Upcoming |

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Python · FastAPI |
| Computer Vision | OpenCV · face_recognition · DeepFace |
| Frontend | React |
| Database | PostgreSQL |
| Streaming | WebSockets |
